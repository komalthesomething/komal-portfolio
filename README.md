# Komal Rajput — Portfolio Website

Static portfolio website for GitHub Pages.

## Public by design
The site contains portfolio case studies, screenshots, a resume, and contact links.
Full Excel models and the SQL database are intentionally kept out of the public website so detailed working files can be shared selectively with genuine clients.

## Files
- index.html — website
- styles.css — design
- images/ — project previews
- assets/ — public resume

## Deploy on GitHub Pages
1. Create a public GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Go to Settings → Pages.
4. Choose “Deploy from a branch”.
5. Select `main` and `/ (root)`.
6. Save.

Before publishing, update the LinkedIn URL/email in `index.html` if needed.
